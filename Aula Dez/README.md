# Aula Dez - GET, POST e EJS

Precisa de Node.js e npm. No VS Code, abra `FULLSTACK_fr19` e use **Terminal → Novo Terminal**:

```powershell
cd "Aula Dez"
npm.cmd install express ejs colors body-parser
node Servidor.js
```

Abra [http://localhost/home.html](http://localhost/home.html).

Mantenha o terminal aberto. Para parar, pressione **Ctrl+C**.

Este é o exemplo da aula. Para usar a atividade completa de cadastro e login, abra o **LAB 8**.

O servidor usa a **porta 80**. Pare qualquer outro servidor nessa porta antes de iniciar este.

Na próxima vez, basta entrar nesta pasta e executar `node Servidor.js`.
