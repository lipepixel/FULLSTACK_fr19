# LAB 9 - Blog

Precisa de **Node.js 22.13 ou superior** e npm. No VS Code, abra `FULLSTACK_fr19` e use **Terminal → Novo Terminal**:

```powershell
cd "LAB 9"
npm.cmd ci
npm.cmd start
```

Abra [http://localhost/blog](http://localhost/blog).

Clique em **Criar novo post**, preencha os campos e publique. O banco SQLite é criado automaticamente e mantém os posts após reiniciar.

Mantenha o terminal aberto. Para parar, pressione **Ctrl+C**.

O servidor usa a **porta 80**. Pare o LAB 7 ou o LAB 8 antes de iniciar este.

Na próxima vez, basta entrar nesta pasta e executar `npm.cmd start`. O GitHub Pages não executa este servidor.
